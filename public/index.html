برمجة شريحة الـ NFC

كتابة الرابط الثابت في الشريحة

متصفحك يدعم برمجة الـ NFC مباشرة (Web NFC API)

اضغط على الزر أدناه ثم قرّب بطاقة أو شريحة الـ NFC من ظهر هاتفك لكتابة الرابط فوراً.

طريقة البرمجة عبر تطبيق NFC Tools (للآيفون والأندرويد):
  1. انسخ الرابط الثابت للبطاقة من لوحة التحكم.
  2. حمّل تطبيق NFC Tools مجاناً من متجر التطبيقات.
  3. اختر Write (كتابة) ثم Add a record (إضافة سجل).
  4. اختر Custom URL / URI وألصق الرابط الثابت.
  5. اضغط على Write وقرّب الشريحة من الهاتف لثانية واحدة فقط.
✨ مبروك! الآن تمت برمجة البطاقة للأبد ولن تحتاج لتكرار هذه الخطوة عند تغيير الرابط الهدف.
