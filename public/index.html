NFC Chip Programming Guide

Write the permanent URL into the NFC chip once and never touch it again!

1

Install the free "NFC Tools" App

Available free on the Apple App Store (iPhone) and Google Play Store (Android).

2

Copy the Permanent Tag URL

From the "My Cards" tab, tap "Copy Link" on any card (e.g. .../c/card-ksnjv).

3

Write the URL to the physical NFC chip

Open NFC Tools → select Write → Add a record → Custom URL / URI → Paste URL → Tap Write and hold the chip to the back of your phone.

✓

Done! Ready to redirect instantly

Whenever customers tap the card, it redirects seamlessly. You can change destination URLs from this dashboard at any time!
