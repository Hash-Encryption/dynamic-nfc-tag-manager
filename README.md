# 📱 نظام إدارة بطاقات NFC الذكية والتحويل الديناميكي (Dynamic NFC Tag Manager)

> نظام ويب متكامل وعصري لإدارة شرائح وبطاقات الـ NFC الذكية مع إمكانية تحويل الروابط ديناميكياً وتعديل الوجهة في أي لحظة بضغطة زر واحدة دون الحاجة لإعادة برمجة الشريحة.

## 🌟 الفكرة الأساسية ومميزات النظام:

1. **الرابط الثابت والبرمجة لمرة واحدة فقط:**
   - تبرمج الشريحة بالرابط الدائم (مثال: `domain.com/c/card-1`).
   - تقوم بتغيير "الرابط الهدف" (Target URL) في أي وقت ومن أي جهاز من لوحة التحكم، وسيتم التحويل فوراً.

2. **محرك التحويل فائق السرعة (Redirect Engine):**
   - تحويل فوري (HTTP 302 / Fast JS replace) بأقل من 10ms.
   - كشف تلقائي لنوع الجهاز ونظام التشغيل (iPhone, Android, Desktop) والمتصفح وتسجيلها في التحليلات.
   - زيادة عداد المسح (+1) وحفظ وقت المسح الأخير.
   - صفحة أنيقة وتنبيه فوري إذا كانت البطاقة متوقفة مؤقتاً.

3. **صفحة الملف الشخصي الرقمي (Digital Business Card):**
   - إمكانية تحويل البطاقة إلى صفحة هبوط شخصية متكاملة (Linktree-style).
   - زر مباشر **"حفظ جهة الاتصال في الهاتف"** يقوم بتوليد وتحميل ملف `vCard (.vcf)` قياسي ليضيفك مباشرة لجهات اتصال الزائر.
   - أزرار التواصل السريع: اتصال هاتفي، مراسلة واتساب، بريد إلكتروني، روابط التواصل الاجتماعي.

4. **لوحة تحكم احترافية وعصرية (Dashboard):**
   - واجهة عربية بالكامل مع دعم كامل لاتجاه النص من اليمين للييسار (RTL).
   - متجاوبة 100% مع شاشات الجوال والهواتف الذكية (Mobile-First).
   - الوضع الليلي والنهاري (Dark / Light Mode).
   - إحصائيات سريعة: إجمالي البطاقات، إجمالي المسحات، البطاقات النشطة، البطاقة الأكثر نشاطاً.
   - تعديل فوري وسريع للرابط بضغطة زر واحدة (Inline Quick Edit).
   - توليد وتنزيل رمز QR Code عالي الدقة لكل بطاقة.
   - ميزة برمجة شريحة الـ NFC مباشرة عبر المتصفح باستخدام (Web NFC API) على أجهزة الأندرويد المدعومة.
   - سجل تحليلات تفصيلي لكل بطاقة يوضح نوع الأجهزة ومواعيد المسح.

## 🚀 تشغيل المشروع محلياً (Local Development):

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث).

### الخطوات:

1. قم بتثبيت الحزم:
```bash
npm install
```

2. تشغيل الخادم:
```bash
npm start
```

3. افتح المتصفح على:
```
http://localhost:3000
```

4. بيانات تسجيل الدخول الافتراضية للوحة التحكم:
   - **كلمة المرور:** `admin123`
   *يمكنك تغيير كلمة المرور في أي وقت من زر الإعدادات داخل لوحة التحكم.*

## 📲 دليل برمجة شرائح الـ NFC (طريقة استخدام الرابط):

1. ادخل إلى لوحة التحكم واضغط **"إضافة بطاقة NFC جديدة"**.
2. حدد اسم البطاقة والرابط الهدف (مثال: رابط تقييم جوجل ماب، أو حساب الإنستغرام).
3. اضغط على زر **"نسخ الرابط"** للرابط الثابت للبطاقة (مثال: `https://your-domain.com/c/card-1`).
4. افتح تطبيق **NFC Tools** المجاني على هاتفك (متوفر على App Store و Google Play):
   - اختر **Write (كتابة)** ثم **Add a record (إضافة سجل)**.
   - اختر **Custom URL / URI** وألصق الرابط الثابت.
   - اضغط **Write** ثم قرّب بطاقة الـ NFC من ظهر الهاتف لثانية واحدة.
5. **تمت البرمجة بنجاح!** الآن عندما يمسح أي عميل البطاقة ستفتح فوراً، ويمكنك في أي وقت فتح لوحة التحكم وتغيير الرابط الهدف وسيعمل التغيير فوراً دون لمس الشريحة مجدداً.

## ☁️ الربط مع قاعدة بيانات سحابية (Supabase):

إذا كنت ترغب بنقل البيانات من التخزين المحلي إلى سحابة Supabase:
1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. انسخ محتويات الملف `supabase_schema.sql` والصقها داخل الـ SQL Editor في Supabase واضغط Run.
3. ستتكون الجداول مع سياسات الأمان والحماية (RLS) تلقائياً.
